# Dungeon Ledger — GitHub Pages

A mobile-friendly static D&D character builder and character sheet. No spell lists or spell tracking. Character data stays in the current browser/device; use JSON export/import for backups.

## Publish it
1. Create a public GitHub repository named `dungeon-ledger`.
2. Upload `index.html`, `manifest.webmanifest`, and `sw.js` into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After publishing, the site URL will look like `https://YOUR-USERNAME.github.io/dungeon-ledger/`.
7. Open it in Safari on iPhone → Share → **Add to Home Screen**. If offered, enable **Open as Web App**.

## Limitations
This is a functional character tracker/calculator, not a complete official rules database. It does not include all sourcebook content, class feature automation, every multiclass prerequisite, or complete official species/background options. Add your choices and verify rules with the books you use. The HP estimate uses one hit die for all class levels; use manual HP for an exact multiclass total. Unofficial fan-made tool; not affiliated with Wizards of the Coast.
